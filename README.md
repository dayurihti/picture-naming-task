**Picture Naming Task**

Picture Naming Task is an audiovisual-based task to measure individual performance of switching between languages. 
The paradigm is adapted from Bonfieni (2018), with several adjustment according to pilot procedure involved Indonesian college student participants.
The picture stimuli contained in this task are from MultiPic (Dunabeitia, 2018).
The output from this task is a set of audio files. Furthermore, you can extract the reaction time using tool on my other repository, https://github.com/dayurihti/reaction-time-extraction.git

This task consist of 3 blocks (Practice, Non-Switching Block, Switching Block.)
Participant is asked to name picture appeared on each trials, based on the language cue that follows.

**NOTES**

1. Please run the task on PsychoPy 25.2.0 (beta) because the task is sensitive with the software version. 
2. When opening PsychoPy builder, please open the microphone settings on each trials, and set up the recording device you want to use properly.
3. You can adjust the language cue (on the "language_cue" folder) with the other country flags based on your research needs.
